# 专武叠层的测试

已知细节：角色生命值变化是服务器端确认后的结果

## 生命值叠层

先确定一个可能较简单的：专武生命值上限调整是否也有 0.5 秒的间隔？

00:00:00.701：钟离加血
00:00:00.784：芙芙吃到一层，+0.083
00:00:00.984：夜兰加血，+0.283，超过了专武的0.2秒判定标准
00:00:01.084：芙芙吃到二层，+0.1，1.084 - 0.784 = 0.3

可见，没有 0.5 秒的间隔限制

再来看专武触发生命值上限变化的时机

假设过程：治疗队友 -> 通知服务器 -> 服务器返回 -> 芙芙或队友血条变化 -> 芙芙生命值上限增加

先用芙芙的天赋治疗来尝试一下：芙芙在前台，阿忍治疗芙芙，溢出触发芙芙天赋治疗队友

为什么芙芙生命值上限增加不是和队友血条变化同时呢？为什么延迟了 0.1 秒？

测试的困难点：

一、因为要观察芙芙生命值变化的话，芙芙必须在前台，因此我们需要一个能奶后台的后台奶
		* 目前满足需求有：吃料理 ，芙芙天赋
二、治疗不像攻击有命中特效，无法知道治疗的时间点

假设 2 秒间隔能保持，设第一次天赋治疗的时间点为 x, 网络延迟为 y, 则：

x + y = 13.987				x + y = 13.987
x + 2 + y = 16.003		x + y  = 14.003
x + 4 + y = 17.953		x + y = 13.953
x + 6 + y = 19.987		x + y = 13.987

14.003 - 13.905 = 0.098

如果 13.905 时 y = 0.05，则 x  = 13.855
14.003 - 13.855 = 0.148
13.885 - 11.768 = 2.117

如果芙芙的治疗不是严格的 2 秒，则上面的数据就变得不可信了
