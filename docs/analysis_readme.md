从目前通过开源的Grasscutter项目的分析来看，出伤是在客户端计算，服务端验证

因此，制定以下几个分析原则

* 出伤按命中的时间点来计算
* 出伤以及气氛值都是在客户端计算的
* 出伤、生命值变动、buff生效都需要服务端确认
	* 在服务端没确认前，如果恰好客户端要计算伤害、气氛值之类的，都不会未经确认的 buff
	* 尽管如此，像万叶扩散增伤之类的不需要这么严格，因为切人的时间就足够收到服务端回执了
	* 像夜兰大招增伤这样飘忽不定的，也一秒一秒来就行，不需要再额外加延迟
	* 像芙芙一命这样的是不需要服务端回执的，这是固定的数值 buff，与时间无关
	* 目前受影响较大的就是芙芙的大招增伤了
