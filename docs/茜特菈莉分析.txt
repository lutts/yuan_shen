极端充能分析
=============
一轮把掣电树打到50%以下25%以上血时，希诺宁需要190充能才能稳定每轮开大，以此为基准计算奶奶的充能需求

4 * 3 * 1.9 + 6 * 2 + x * 0.6 * 1.9 = 60

x = (60 - 4 * 3 * 1.9 - 6 * 2) / (0.6 * 1.9)

x = 22

这期中怪的血量降到了 50% 以下，多产了一颗晶球，如果少了这颗晶球，就少了三个微粒

则

4 * 3 * x + 6 * 2 + 19 * 0.6 * x = 60

(4 * 3 + 19 * 0.6)x = 60 - 12 = 48

x = 48 / (4 * 3 + 19 * 0.6)
x = 205

如果是奶奶，则需要的充能为：

5 * 3 * x + 6  + 19 * 0.6 * x = 60

x = (60 - 6) / (5 * 3 + 19 * 0.6)

x = 205

如果不是勇者套，则需要 230 左右的充能

黑耀：x = 60 / (5 * 3 + 19 * 0.6) = 230

四命加 16 点充能，则

x = (60 - 6 - 16) / (5 * 3 + 19 * 0.6)

x = 144 -> 150，相当于可以用精通沙了。。。

黑耀：x = (60 - 16) / (5 * 3 + 19 * 0.6) = 170
